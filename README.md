# DeepSeek-UI-UX: навык красивого веб-дизайна для ИИ

**DeepSeek-UI-UX** — это набор инструкций (навык), который превращает DeepSeek и другие ИИ в старшего продуктового дизайнера и фронтенд-инженера. Без запуска скриптов и установки зависимостей: вы копируете промпт, ИИ подбирает стиль из готовой базы и генерирует самодостаточный `index.html`.

> **Суть навыка:** 192 палитры · 74 пары шрифтов · 130 UX-правил · 34 паттерна страниц · 79 стилей[reference:0].

## Как это работает?

Навык построен на строгой последовательности этапов. DeepSeek не пишет код, пока не прочитает источник навыка и не согласует дизайн-бриф с вами[reference:1].

1. **Доступ к навыку:** ИИ читает `FULL.md` (или `README.md` + модули) и подтверждает числа из шапки. Если прочитать не удалось — честно сообщает об этом и останавливается[reference:2].
2. **Описание задачи:** Если сайт не описан, ИИ задаёт один вопрос: «Какой сайт нужен?»[reference:3].
3. **Уточняющие вопросы:** ИИ задаёт 5–8 нумерованных вопросов с вариантами по умолчанию (аудитория, разделы, тон, данные, стек, примеры)[reference:4].
4. **Отчёт данными из навыка:** До кода ИИ выводит Design Brief: палитра `P#` с 6 hex-цветами, шрифты `F#`, паттерн `L#`, стиль и 3 ключевых эффекта[reference:5].
5. **Код:** Один самодостаточный `index.html` (HTML + CSS + минимальный JS). Все цвета, радиусы, тени и отступы вынесены в CSS-переменные `:root`[reference:6].
6. **Проверка и сверка:** ИИ проверяет код, проходит чеклист `✅/❌` и выдаёт блок «Использовано из навыка: …» с номерами палитр, шрифтов и паттернов[reference:7].

## Начало работы

### Быстрый старт (1 минута)

1. **Скопируйте промпт** из блока «Промпт для DeepSeek» в README репозитория (на GitHub есть кнопка копирования)[reference:8].
2. **Откройте новый чат в DeepSeek**, вставьте промпт целиком и отправьте. Строку `ЗАДАЧА` можно заполнить сразу или оставить пустой[reference:9].
3. **Ответьте на вопросы.** DeepSeek сам спросит, какой сайт нужен, затем задаст уточняющие вопросы и только потом начнёт писать код[reference:10].
4. **Скопируйте готовый `index.html`**, сохраните файл и откройте в браузере[reference:11].

### Технический стек

Навык не требует установки библиотек или запуска сервера. Для работы нужны только:

- **DeepSeek** (или другой ИИ с доступом к ссылкам) — выполняет роль дизайнера и разработчика.
- **Браузер** — для просмотра готового `index.html`.

### Заполнение строки «ЗАДАЧА»

В конце промпта есть строка `ЗАДАЧА: [...]`. Чем конкретнее описание, тем точнее результат[reference:12].

**Хорошие примеры:**

- `Лендинг барбершопа в Казани: запись онлайн, цены, 3 мастера, тёмный стиль, телефон +7 000 000-00-00`
- `Портфолио фотографа: галерея на главной, страница «Обо мне», контакты, минимализм`
- `Дашборд для интернет-магазина: выручка, заказы, топ-товары, светлая и тёмная тема`

Можно оставить пустым: DeepSeek задаст вопрос сам[reference:13].
