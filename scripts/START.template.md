# Стартовые промпты

Замени `[ЗАДАЧА]` на описание сайта: ниша, аудитория, разделы, тон, что должно быть на странице. Отправляй целиком одним сообщением в новом чате.

## Вариант A: по ссылке на репозиторий

```
Ты старший продуктовый дизайнер и фронтенд-инженер. Обязательное условие: ты работаешь строго по навыку из моего репозитория. Без него сайт не создавай.

Навык: https://github.com/{{REPO}}
Полный текст одним файлом: {{RAW}}/dist/FULL.md

ШАГ 0. Доступ.
Прочитай README.md и dist/FULL.md. Если не можешь открыть или прочитать их, напиши одну фразу «НЕ МОГУ ПРОЧИТАТЬ НАВЫК» и остановись. Не придумывай содержимое, я пришлю текст сам.

ШАГ 1. Отчёт о навыке (до любого кода).
Подтверди прочтение: назови выбранную строку из product-map.md, а из таблиц укажи номера и значения: палитра P# (6 hex-цветов), шрифты F# (названия и проверка кириллицы), паттерн лендинга L# (порядок секций).

ШАГ 2. Design Brief строго в формате из README:
PATTERN / STYLE / COLORS / TYPOGRAPHY / KEY EFFECTS / AVOID.

ШАГ 3. Код.
Один самодостаточный index.html. Все цвета, радиусы, тени и отступы идут через CSS-переменные из Brief. Никаких палитр и шрифтов вне таблиц навыка; если отходишь от них, объясни почему одной строкой.

ШАГ 4. Самопроверка.
Пройди чеклист из README, отметь каждый пункт ✅ или ❌ и исправь ❌ до выдачи. В конце напиши строку «Использовано из навыка: P#, F#, L#, стиль, правила UX №…».

Пиши ответ на русском, код и комментарии на английском.

ЗАДАЧА: [ЗАДАЧА]
```

Выполни шаги 1-4:

## Вариант C: правки готового сайта

```
Внеси изменения в сайт, не выходя из Design Brief и правил навыка (токены, палитра, шрифты, чеклист). Перед кодом одной строкой назови, какие правила навыка затронуты. После кода снова пройди чеклист (✅/❌).

ИЗМЕНЕНИЯ: [ЧТО ПОМЕНЯТЬ]
```

## Как проверить, что модель не выдумала

Открой `modules/palettes.md`, `modules/typography.md` или `modules/landing-patterns.md` и найди номер, который назвала модель. Если hex-цвета, названия шрифтов или порядок секций не совпадают с таблицей, она не читала навык. Отправь вариант B.
